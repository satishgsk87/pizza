🍕 Foodie’s Delight

A simple and interactive restaurant website built using HTML.
It showcases menu categories, pricing, offers, videos, and contact details.

📌 Project Description

Foodie’s Delight is a beginner-friendly static website that demonstrates various HTML elements such as:

Headings

Lists (Ordered & Unordered)

Tables

Audio & Video

Images

Iframe (Google Maps)

Internal navigation links

Details & Summary section

🚀 Features

🔗 Navigation links (Jump to sections)

🖼️ Banner image

📋 Menu categories

🔥 Top-selling items

💵 Price table

🎧 Audio jingle

🎥 Kitchen video

📍 Embedded Google Map location

📞 Contact section

⬆ Back to top link

🛠 Technologies Used

HTML5

📂 How to Run

Download or clone the repository.

Open the file index.html.

Run it in any web browser (Chrome, Edge, Firefox, etc.).

📸 Preview

Open the website in your browser to see:

Interactive navigation

Multimedia content

Restaurant information layout
